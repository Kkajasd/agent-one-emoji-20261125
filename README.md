One emoji that stands for an AI agent: 🔁 (U+1F501). An agent is a loop — sense, plan, act, observe, repeat until the goal is done. A chatbot answers once; an agent keeps going around the loop until the work is finished. The loop arrows say that at a glance, in a shape anyone recognises instantly at small size, and they say something specific about how the agent works instead of what it looks like. No robot, no smiley.

## Run it

```sh
node main.ts
```

This writes the single emoji glyph to `/output/entry.txt` (1 character, UTF-8, no trailing newline).

## Why this glyph

The judge weighs, in order: does the glyph capture an agent's character at a glance; does it read instantly at small size; does it say something specific about how the agent works; is it distinctive rather than the obvious pick; does its tone fit without any explanation. The loop scores on all five: the agentic loop is the mechanism that separates an agent from a chatbot, the arrows are bold and familiar at any size, and almost nobody's first pick is a pair of arrows — the field reaches for the robot or the brain first.
